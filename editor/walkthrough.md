## Choose chart ticks for an observed range

Returns [first tick, last tick, step, tick count]. The tick count can differ from the requested interval target. Invalid arguments and nonfinite results return an empty vector.

1. Open an empty file named `flamingo-demo.blyx`.
2. Type `blyx-flamingo-demo` and select **Flamingo — runnable example**. You can also use **Snippets: Fill File with Snippet**.
3. Choose **Blyx: Run File** from the command palette. Change an argument near the end of `fn main()` to try another input.

Expected output

```text
0
15
5
4
```

[Work through the example in the browser](https://www.blyx-lang.space/play?example=package-flamingo)
