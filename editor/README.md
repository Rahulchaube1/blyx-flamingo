# Blyx Flamingo

Produce chart-ready axis limits and labeled tick spacing from raw data.

This extension includes the Blyx Flamingo 0.1.0 source, a runnable example and completions for its public functions. It uses the Blyx Language extension for syntax highlighting and execution.

## Run in the editor

1. Open an empty file named `flamingo-demo.blyx`.
2. Type `blyx-flamingo-demo` and select **Flamingo — runnable example**. You can also use **Snippets: Fill File with Snippet**.
3. Choose **Blyx: Run File** from the command palette. Change an argument near the end of `fn main()` to try another input.

Expected output

```text
0
15
5
4
```

## Use Flamingo in a project

Extract the starter into a new folder. It contains `main.blyx`, the licensed framework source in `vendor/flamingo`, and a VS Code task. With the Blyx 0.2.1 compiler and host toolchain installed, run `blyxc native-run main.blyx` from that folder. Type `blyx-flamingo-` in a Blyx file to see the framework completions. [Download the starter ZIP](https://github.com/Rahulchaube1/blyxxxx/releases/download/framework-editors-v0.1.0/blyx-flamingo-starter-0.1.0.zip)
