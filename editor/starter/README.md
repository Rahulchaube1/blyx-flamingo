# Flamingo starter

Produce chart-ready axis limits and labeled tick spacing from raw data.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Flamingo** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
0
15
5
4
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/flamingo) · [View the release](https://github.com/Rahulchaube1/blyx-flamingo/releases/tag/v0.1.0)
